**GNU Wget** es una herramienta _Open Source_ patrocinada por la [Free Software Foundation](https://www.gnu.org/software/wget/#mission-statement) que permite realizar descargas no interactivas desde la Web de forma confiable y sencilla.

Wget soporta los protocolos más usados para la transferencia de archivos:

- HTTP
- HTTPS
- FTP

Además, funciona correctamente incluso cuando se utiliza un proxy entre tu equipo y el servidor.

## __¿Por qué usar GNU Wget?__

Wget está especialmente diseñado para manejar conexiones lentas o inestables. Algunas de sus ventajas son:

- Reintentos automáticos en caso de fallos en la conexión.
- Descargas que pueden reanudarse si se interrumpen.
- Capacidad de descargar sitios web completos para navegación offline.
- Soporte robusto para proxies y certificados SSL/TLS.

## __Instalación__

### __Windows__

Puedes descargar la última versión compatible para Windows desde este enlace:  
[https://eternallybored.org/misc/wget/](https://eternallybored.org/misc/wget/){:target='_blank'}

### __Linux / macOS__

Generalmente viene preinstalado en muchas distribuciones. Si no es tu caso, instálalo con tu gestor de paquetes, por ejemplo:

```terminal
sudo apt install wget          # Debian/Ubuntu
sudo yum install wget          # CentOS/RHEL
brew install wget              # macOS (Homebrew)
```

## __Sintaxis y opciones básicas__

Wget utiliza la biblioteca GNU getopt para procesar los argumentos de línea de comandos, por lo que cada opción puede usarse en forma corta o larga. Puedes combinar estilos y ordenar las opciones libremente.

Ejemplo:

```terminal
wget -r --tries=10 http://fly.srk.fer.hr/ -o log.txt
```

* `-r` o `--recursive`: descarga de forma recursiva (útil para sitios web).
* `--tries=10`: intenta descargar hasta 10 veces si hay fallos.
* `-o log.txt`: guarda la salida en un archivo log.

### __Validación de certificados SSL/TLS__

Si deseas evitar que Wget valide el certificado SSL (no recomendado por seguridad), puedes usar la opción:

```terminal
wget --no-check-certificate https://ejemplo.com/archivo.tar.gz
```

## __Usos comunes de Wget__

**Descargar archivos simples:**

```terminal
wget https://example.com/archivo.zip
```

**Descargar un sitio web completo para uso offline:**

```terminal
wget --mirror --convert-links --adjust-extension --page-requisites --no-parent https://example.com
```

**Descargar con límite de velocidad (para no saturar la red):**

```terminal
wget --limit-rate=200k https://example.com/archivo.iso
```

## __Uso de Wget en scripts Bash__

Wget es muy útil para automatizar descargas en scripts. Por ejemplo:

```bash
#!/bin/bash
URL="https://example.com/data.csv"
DESTINO="/home/usuario/descargas/data.csv"

wget -q --show-progress -O "$DESTINO" "$URL"

if [ $? -eq 0 ]; then
  echo "Descarga completada exitosamente."
else
  echo "Error en la descarga."
fi
```
